# CS 1090B HW1

## Local Environment Setup

(only advisable if you have a GPU)

1. Install [uv](https://docs.astral.sh/uv/#installation) for Python virtual environment
   and package management.
2. Run `uv sync` to create the virtual environment in .venv and install the
   required dependencies.
3. Run `source .venv/bin/activate` to activate the environemnt
4. Launch Jupyter Lab with `jupyter lab`.

## Using Open OnDemand GPU Compute Resources

1. Go to [https://ood.huit.harvard.edu](https://ood.huit.harvard.edu) (also
   linked as "Open OnDemand" on Canvas).
2. Click "Interactive Apps" > "Jupyter Lab - CS 1090B(GPU)
3. Launch the Jupyter App, wait, and connect when ready.
4. Click the up arrow in Jupyter Lab's file browser to upload your files.
